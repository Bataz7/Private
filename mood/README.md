# Mood Bot 🌈

بوت ديسكورد خفيف يرسل كل يوم الساعة **2:30** رسالة خاصة لشخص تحدده:
**"كيف كان يومك؟"**، ويسجّل مزاجه ووش اللي خلى يومه حلو أو سيء، ويطلع **تقارير احترافية** تبين إذا مزاجه يتحسن.

## وش يسوي؟

| الميزة | التفاصيل |
|---|---|
| 🕑 سؤال يومي | يوصله في الخاص كل يوم 2:30 مع 5 أزرار (ممتاز ← سيء جداً) |

| 🤖 ذكاء اصطناعي | (اختياري) يرد عليه رد ودود بلهجتنا، ويحلل التقارير ويعطي نصائح مخصصة |

| 😄 ايموجيات خاصة | 6 ايموجيات مرسومة للبوت، يرفعها تلقائياً أول ما يشتغل |
| 🔥 سلسلة | يحسب كم يوم ورا بعض سجّل |

## الأوامر

| `/status` | الإعدادات ووقت السؤال وحالة الـ AI |

## التشغيل (5 دقايق)

**1) سوّ البوت في ديسكورد**
1. ادخل https://discord.com/developers/applications ← **New Application**
2. من **Bot** ← **Reset Token** وانسخ التوكن
3. من **Installation** فعّل **User Install** و **Guild Install**، وفي الـ scopes حط `applications.commands` و `bot`
4. افتح رابط التثبيت وضيف البوت لسيرفر فيه الشخص (أو خله يثبته عنده كـ User App) — لازم يكون فيه طريقة يقدر البوت يرسل له خاص

**2) جيب الـ ID**
في ديسكورد: الإعدادات ← Advanced ← فعّل **Developer Mode**، بعدين كليك يمين على الشخص ← **Copy User ID**.

**3) الإعدادات**
```bash
cp .env.example .env
```
وعبّي: `DISCORD_TOKEN` و `TARGET_USER_ID` (الشخص) و `OWNER_ID` (أنت).
وقت السؤال `CHECKIN_TIME=14:30` (يعني 2:30 الظهر — لو تبيه 2:30 الفجر حطه `02:30`).

**4) شغّل**
```bash
./run.sh        # لينكس / ماك
run.bat         # ويندوز
```
أو يدوياً: `pip install -r requirements.txt` ثم `python bot.py` (يحتاج Python 3.10+).

## الذكاء الاصطناعي (اختياري)

حط مفتاح من https://console.anthropic.com في `ANTHROPIC_API_KEY` وخلاص.
البوت يستخدم Claude (`claude-opus-5-5` افتراضياً، وتقدر تغيره من `AI_MODEL`) عشان:
- يرد على كل تسجيل برد قصير يفهم وش كتب الشخص ويلاحظ الأنماط
- يحلل التقرير: ملخص، وش يحسن المزاج، وش يخربه، و3 نصائح عملية مبنية على بياناته

بدون مفتاح يشتغل كل شي عادي، بس الردود جاهزة والتحليل يعتمد على أكثر الأشياء تكراراً.
